# Chandla Steel Works

A MERN Stack based web application developed for a steel welding business.  
This project provides a digital platform to showcase steel products, manage products through an admin panel, and allow users to browse and place orders.

## Features

### User Features
- User registration and login authentication
- Browse available steel products
- Search products
- View product details
- Add products to cart
- Place orders
- Order tracking
- Contact form for customer queries

### Admin Features
- Admin authentication
- Add new products
- Edit product details
- Delete products
- Manage user orders
- Update order status
- View customer queries

## Technologies Used

### Frontend
- React.js
- React Router
- Redux Toolkit
- Bootstrap
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

### Other Tools
- Cloudinary (Image Storage)
- Multer (Image Upload)
- Postman (API Testing)
